## Scoring decision

The category is already visible on the Windows matrix. The [public scoring methodology](https://www.edr-telemetry.com/scores#optional-telemetry) requires 75% support across the scoped vendor set; only Yes and Via EnablingTelemetry count toward that threshold. Across the current 24 columns, the baseline is 8/24, this PR would make it 9/24, and #181 would bring it to 10/24. Even excluding Sysmon as a non-vendor comparator, that would be 10/23. That remains below the normal threshold. The project maintainer directed an explicit scoring exception for this category. The EDR-Telemetry Windows sync applies it to the canonical category flag at the existing one-point weight, uniformly for the entire matrix. This needs a Cloud Function code deployment followed by a Windows data sync and public verification. No website code changes are part of this PR.
